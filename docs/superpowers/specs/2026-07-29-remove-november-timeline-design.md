# 删除11月时间轴设计

## 目标

让“11月里约资源调研”保持纯资源资料库定位，移除独立时间轴及其导航入口，减少领导浏览前的非必要信息层级。

## 已确认方案

- 删除首页完整“整个11月，一眼看清”时间轴区块。
- 删除顶部导航中的“11月时间轴”。
- 删除首屏“查看11月时间轴”次按钮，只保留“浏览全部资源”。
- “里约四类资源”成为首页第一个内容模块，编号调整为 `01`。
- “信息边界”模块编号调整为 `02`。
- 保留每张资源卡片和资源详情中的具体日期、日期状态与筛选能力。
- 不增加月历、密度条或其他替代时间可视化。

## 验收标准

- 服务端页面不再包含时间轴标题、时间轴导航或时间轴条目结构。
- 四类资源、收藏、搜索、筛选、图片详情和社媒数据不受影响。
- 桌面端与手机端首屏均只有一个主要行动按钮。
- 自动测试、代码检查和静态发布构建通过后更新 Cloudflare 与 GitHub Pages。
