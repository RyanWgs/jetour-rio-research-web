# Research Card Links & Images Design

## Goal

在现有捷途国际里约研究网页中，为全部候选卡片增加清晰的外部链接，并按用户确认的方案 C 增加真实图片、官方 Logo 或公开头像，提高识别效率和资料可信度，同时保持黑底白字、苹果式简约风格。

## Confirmed Scope

- 音乐节、本地庆典、体育与演艺 IP：尽可能使用活动或机构的真实图片。
- 户外、室内、沙滩场地：尽可能使用场地真实图片。
- 主流媒体、行业媒体：使用官方 Logo。
- Content Creator：使用公开头像或频道 Logo。
- 每张卡片必须显示至少一个可点击的官网、官方账号或公开来源链接。
- 没有可靠图片来源的项目继续使用纯文字卡片，不使用生成图或不相关图库图。

## Image Data Contract

研究记录可增加可选 `image` 字段：

```js
image: {
  src: 'https://...',
  alt: '准确描述图片内容',
  kind: 'photo | logo | avatar',
  sourceLabel: '图片来源名称',
  sourceUrl: 'https://...',
  licenseNote: '官方公开图片 / Wikimedia Commons许可信息 / 发布前需复核'
}
```

- `src` 必须是稳定的 HTTPS 图片地址或下载到项目中的已核验本地资产。
- `alt` 必须描述项目主体，不能使用“图片”“照片”等空泛文字。
- `sourceUrl` 必须指向图片原始页面或官方主体页面。
- 所有图片须记录来源与核验日期。

## Source Selection

优先级从高到低：

1. 主办方、场馆、俱乐部、媒体或创作者的官方媒体资料与公开图片。
2. Wikimedia Commons 等提供清晰许可信息的图片。
3. 官方平台头像、频道 Logo 或品牌 Logo。

不使用：

- 无来源的搜索引擎缩略图。
- 与候选项目无直接关系的通用图库图。
- 带有第三方水印或无法确认主体的图片。
- 需要绕过登录、付费墙或访问限制才能取得的图片。

## Card Presentation

- 有图片的活动、IP、场地卡片：顶部使用约 `16:9` 的横向真实图片。
- 媒体 Logo 和创作者头像：使用较克制的 Logo/头像容器，不强行裁切为活动大图。
- 图片默认低饱和或灰度处理，悬停时轻微恢复色彩。
- 图片下方或卡片底部显示简短“图片来源”链接。
- 卡片底部增加明确的“访问官网 ↗”或“访问官方账号 ↗”。
- 详情弹窗继续展示全部研究来源，并增加图片来源与许可备注。

## Failure Handling

- 图片加载失败时隐藏图片容器，卡片自动回到当前纯文字布局。
- 图片失败不能影响卡片高度、筛选、排序或详情弹窗。
- 外部链接使用新标签页，并带 `rel="noopener noreferrer"`。
- 卡片链接与详情来源链接使用不同文案，避免用户误解“官网”和“研究证据”。

## Responsive Behavior

- 桌面：图片位于卡片顶部，维持三列或两列卡片布局。
- 平板：图片比例保持不变，文字区域继续完整显示。
- 手机：图片使用横向比例，Logo/头像适当缩小，不增加横向滚动。
- 图片来源和官网链接必须保持可点击尺寸与键盘焦点状态。

## Verification

- 数据测试：有 `image` 的记录必须包含 `src`、`alt`、`kind`、`sourceLabel`、`sourceUrl` 和 `licenseNote`。
- 渲染测试：卡片必须存在官网/官方账号链接；有图记录必须输出图片来源。
- 交互测试：图片失败时隐藏；详情弹窗仍能正常打开与关闭。
- 视觉检查：1440×1000、1024×1366、390×844 无横向溢出。
- 发布前复核：图片版权、Logo/头像使用边界、链接稳定性及公开仓库安全。

## Out of Scope

- 不制作生成式图片。
- 不修改当前研究结论、候选数量或排序逻辑。
- 不在本轮上传 GitHub 或公开发布。
- 不采集创作者后台数据、私人联系信息或报价。
