# 11月里约资源资料库互动改版设计

## 目标

把现有“领导决策版”网页改造成一份聚焦资源查阅的纯资料库。老板打开页面后，应能快速理解整个11月有哪些里约资源、资源影响力如何、可以怎样合作，并通过图片详情、筛选和收藏形成自己的候选清单。

## 页面定位与信息结构

- 页面及浏览器标题统一为“11月里约资源调研”。
- 删除“先做4个决定”完整章节，以及“64候选资源 / 4决策模块 / 30天完整窗口 / 700目标人数”统计模块。
- 顶部导航删除“决策结论”。
- 页面顺序调整为：主视觉标题、11月时间轴、里约四类资源、信息边界。
- 资源章节标题使用“里约四类资源”，不再使用“按决策展开”等决策型表述。
- 主视觉按钮直接引导至全部资源；时间轴保留为11月活动的快速入口。

## 资源内容

- 现有64项资源的数据结构、分类、影响力、借势价值、玩法、风险和公开来源保持不变。
- 为每一项资源新增独立中文简介，长度控制在约50至100个中文字符。
- 简介回答三个问题：资源是什么、在里约或巴西的地位是什么、为什么值得本项目关注。
- 简介只使用现有已核验信息，不新增未经来源支持的规模、粉丝量、日期或商业权益结论。
- 图片存在时，整张图片成为可点击入口；无图片的资源仍可通过卡片按钮进入完整详情。

## 资源详情交互

- “查看决策详情”统一改为“查看资源详情”。
- 点击资源图片或“查看资源详情”按钮，打开同一个资源详情弹窗。
- 弹窗顶部显示图片、资源名称、地点和新增的中文简介。
- 下方继续显示影响力判断、借势价值、建议玩法、风险与前置条件、公开来源和图片使用说明。
- 图片上提供清晰但克制的“点击查看资源详情”提示。
- 弹窗支持可见关闭按钮、键盘 Escape 关闭和移动端内部滚动。

## 收藏功能

- 每张资源卡片提供独立收藏按钮，未收藏与已收藏状态视觉可辨。
- 资源详情弹窗内提供同一收藏操作，卡片与弹窗状态实时同步。
- 资源区提供“仅看收藏”开关，并显示当前收藏数量。
- 收藏与现有分类、子分类、日期状态、搜索和排序条件组合生效。
- 收藏资源 ID 存储在浏览器 `localStorage` 中；刷新页面或在同一设备再次打开时保留。
- 收藏不依赖登录，也不会跨设备同步。存储不可用时，当前会话内仍可收藏，页面不得报错。
- 若“仅看收藏”后没有结果，空状态明确提示用户先收藏资源或关闭该筛选。

## 浏览与视觉互动

- 资源分类导航在进入资源区后吸顶，便于长页面中持续切换四类资源。
- 筛选、搜索、排序和收藏筛选即时更新结果，不整页刷新。
- 卡片首次进入视口时做轻微渐显；图片在指针设备上轻微放大；详情弹窗使用短时淡入与位移动画。
- 动画只增强层级感，不遮挡内容、不延迟操作。
- 遵循 `prefers-reduced-motion`；用户要求减少动态效果时关闭非必要动画。
- 手机端保留足够大的图片和收藏点击区域，避免横向溢出，并控制动画强度。
- 切换详情后关闭弹窗时，列表原有分类、搜索、筛选、排序和滚动上下文不被重置。

## 数据与组件边界

- `src/research-data.js` 保存每项资源的中文简介，作为所有部署版本的统一数据源。
- `app/research-explorer.tsx` 负责选中资源、收藏集合、收藏筛选和详情弹窗协调。
- `app/research-image.tsx` 接收可选点击行为；图片来源链接必须阻止冒泡，仍然直接打开原始来源。
- 收藏读写封装为小型、可测试的纯函数或浏览器安全工具，避免服务端渲染访问 `window`。
- Cloudflare Pages、GitHub Pages和现有应用继续复用同一套页面组件与数据，不复制资源内容。

## 可访问性与失败处理

- 图片点击入口可通过键盘聚焦并用 Enter 或空格打开详情。
- 收藏按钮包含资源名称和当前状态的辅助文本，并设置 `aria-pressed`。
- “仅看收藏”具备明确标签和状态。
- 图片加载失败时继续隐藏图片，但资源文字、收藏和详情按钮可用。
- `localStorage` 读取到无效内容时忽略并回退为空集合。
- 所有外部来源继续在新标签页打开，并保留安全的链接属性。

## 验证标准

- 页面不再出现“先做四个决定”、决策统计模块或“查看决策详情”。
- 主标题与浏览器标题均显示“11月里约资源调研”。
- 64项资源均有非空中文简介。
- 代表性图片可通过鼠标和键盘打开对应资源详情，图片来源链接仍只打开来源页面。
- 卡片与详情弹窗的收藏状态同步；刷新后收藏保留；“仅看收藏”可与其他筛选组合。
- 无收藏、存储异常和图片失败均有可用回退。
- 390px手机宽度和桌面宽度无横向溢出，弹窗可完整滚动，减少动态效果设置生效。
- 应用构建、Cloudflare静态构建、GitHub Pages静态构建、自动化测试和代码规范检查全部通过。
- 更新后的Cloudflare主链接与GitHub Pages备用链接均返回成功状态。

## 不在本次范围

- 登录、账号体系和跨设备收藏同步。
- 收藏清单导出、分享或多人协作。
- 两项资源并排比较。
- 修改现有研究结论、候选数量或重新开展外部调研。
