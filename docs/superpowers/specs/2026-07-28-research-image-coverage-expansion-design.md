# Research Image Coverage Expansion Design

## Goal

在现有捷途国际里约全球用户节研究网页中，尽可能为当前缺图候选补充真实、可识别、可追溯的彩色图片，提高领导浏览效率；不修改研究结论、候选数量或排序逻辑。

## Approved Source Boundary

图片来源按以下优先级使用：

1. 主办方、场馆、俱乐部、政府机构、媒体或创作者官方页面与官方账号公开图片。
2. 权威媒体报道中的活动、比赛、演出、场地实拍图或主办方宣传图。
3. Wikimedia Commons 等带有明确许可信息的主体相关图片。

权威媒体图片必须登记媒体名称、原始报道页面，并在可获得时记录摄影师或 `Divulgação` 署名。所有图片均标注“公开发布前复核转载、品牌、肖像及平台使用许可”。

不使用搜索引擎缩略图、无来源社媒搬运图、网页截图服务、通用图库图、带第三方水印图片或无法确认主体的图片。

## Coverage Rule

- 逐一检查当前缺图的音乐节、本地庆典、体育与演艺 IP、Content Creator 和场地。
- 能找到可靠主体相关图片的候选全部加入视觉登记。
- 媒体继续使用官方 Logo；Content Creator 优先使用公开头像或官方频道标识。
- 经官方页面、权威媒体和可许可图库检查后仍没有可靠图片的候选保留纯文字卡片。
- 不为追求数量使用错图、旧主体图或与候选无直接关系的城市风景图。

## Presentation

- 所有照片、Logo 和头像保留原彩，不应用灰度或黑白滤镜。
- 活动、IP 和场地使用横向真实视觉；Logo 与头像使用克制的居中容器。
- 卡片展示图片来源链接；详情弹窗展示来源与权利提示。
- 外部图片加载失败时隐藏图片容器，卡片继续显示完整文字与官网链接。

## Data and Provenance

每个新增视觉记录继续使用 `src/research-media.js` 的数据契约：

```js
{
  src,
  alt,
  kind,
  sourceLabel,
  sourceUrl,
  licenseNote,
  checkedAt
}
```

同时更新 `research/source-register.md`，记录覆盖数量、来源类型及公开发布前复核事项。

## Verification

- 自动测试确认视觉记录字段完整、图片地址为 HTTPS、类别与图片类型匹配。
- 检查新增图片地址能返回图片内容，排除网页截图占位服务。
- 在活动、IP、媒体/创作者和场地四个模块逐项抽检图片、来源链接和详情弹窗。
- 在桌面、平板和手机尺寸确认原彩显示、无横向溢出、图片失败可回退。
- 记录最终有图数量和仍缺图项目，不能把未核验图片计入覆盖率。

## Publication Boundary

本轮仅更新本地网页，不上传 GitHub、不创建在线公开链接。公开发布前必须再次复核图片转载、品牌 Logo、头像、肖像和平台使用边界，并将获准素材按需要归档为本地文件。
